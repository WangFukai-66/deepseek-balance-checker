# macOS‑shortcut
收集 macOS 自用小工具，基于 AppleScript + 网页脚本，快捷指令一键启动。

## 📂仓库目录
- **deepseek‑balance‑checker**：DeepSeek API 余额查询工具，AppleScript快捷启动
- **autocue**：本地网页提词器，支持 txt / docx，文本自动滚动

## 🚀使用说明
1. 克隆仓库
```bash
git clone https://github.com/WangFukai-66/macOS-shortcut.git
cd macOS-shortcut
```
2. 进入对应工具子文件夹，阅读该目录下 README.md 查看详细使用方法

3. 复制对应 AppleScript，导入macOS「快捷指令」即可一键运行

⚠️提示

• AppleScript脚本内文件路径需要和本地实际文件位置匹配

• 部分网页工具需要网络加载外部依赖库
